# 国産食材こだわりチェーン レストランマップ（富山版）

国産の野菜や肉を積極的に使用している安心・安全な国内チェーンレストランを地図上で探索できるWebマップアプリケーションです。

---

## 🌟 特徴

1. **厳選された国産こだわりチェーンを可視化**
   * **リンガーハット**: 野菜（キャベツ・長ねぎ・玉ねぎ等）および小麦粉が**100%すべて国産**
   * **餃子の王将**: 看板メニュー「餃子」の主要食材（豚肉・キャベツ・ニラ・にんにく・生姜・小麦粉）が**すべて国産100%**
   * **モスバーガー**: 全国約2,500軒の協力農家が育てる安心の**国産生野菜100%**
   * **大戸屋 ごはん処**: 厳選した国産野菜、チルド国産肉、店内調理＆無添加へのこだわり
   * **しゃぶ葉**: 厳選された**国産牛・国産豚**食べ放題コース＆新鮮野菜バー
2. **富山県内の実店舗を網羅**
   * 富山市、高岡市、射水市、氷見市、砺波市などの主要店舗（座標・住所・電話・営業時間・駐車場情報）を収録。
3. **柔軟な絞り込み・検索**
   * 「野菜100%国産」「お肉も国産」のこだわりトグルフィルター
   * エリア（市町村）絞り込み、キーワード検索
   * 店舗選択時の詳細カード（食材ごとの解説、公式産地情報リンク、Googleマップ経路検索）
4. **月1回の自動更新対応**
   * 公式HPの食材・産地ページの稼働監視
   * GitHub Actionsにより、毎月1日に自動で定期チェックを実行し、Vercelへ自動再デプロイ

## 🛠 技術スタック

* **フロントエンド**: React 18, TypeScript, Vite
* **スタイリング**: Tailwind CSS, Lucide Icons
* **地図エンジン**: Leaflet, OpenStreetMap
* **自動更新**: Node.js, GitHub Actions (cron)
* **ホスティング**: Vercel

## 🚀 使い方・ローカルでの起動方法

### 1. 開発サーバーの起動
```bash
# 依存パッケージのインストール（初回のみ）
npm install

# 開発サーバーを起動
npm run dev
```
起動後、ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開いて確認できます。

### 2. 本番用ビルドの確認
```bash
npm run build
```

### 3. 月次自動更新スクリプトの手動テスト
```bash
npm run update-stores
```

## 🌐 Vercelへのデプロイ（公開）手順

本リポジトリは、Vercelの標準設定（ゼロコンフィグ）に対応しています。

1. **GitHubにリポジトリを作成してプッシュ**
   ```bash
   git init
   git add .
   git commit -m "feat: 初回コミット - 国産レストランマップ 富山版"
   git branch -M main
   git remote add origin <あなたのGitHubリポジトリURL>
   git push -u origin main
   ```
2. **Vercelと連携**
   1. [Vercel公式サイト](https://vercel.com/) にログイン
   2. 「Add New...」 ➔ 「Project」を選択
   3. GitHub上の本リポジトリを選択して「Deploy」をクリック
3. **公開完了！**
   * 1〜2分で世界中からアクセス可能なURL（`https://xxx.vercel.app`）が発行されます。
   * 以降は、GitHub Actionsが毎月1日にデータを更新・プッシュすると、Vercelが自動的に最新版を反映します。
